# 3차 수동 검증 (최종 리뷰 수정분)

최종 전체 리뷰에서 나온 Important 3건 + Minor 5건을 고쳤다. 그중 네 가지는 DOM에서만 드러나므로 사람이 확인해야 한다.

## 준비

**코드가 바뀌었으니 스니펫을 먼저 갱신한다.** 이전에 저장해둔 스니펫에는 이번 수정이 없다.

```bash
pbcopy < /Users/dev-soon/workspace/project/claude-vimium/src/claude-vimium.js
```

1. Claude Desktop에서 `Cmd+Alt+I` → **Sources → Snippets**
2. 기존 `claude-vimium` 스니펫을 열고 **전체 선택(`Cmd+A`) 후 붙여넣기(`Cmd+V`)** 로 내용을 갈아끼운다
3. `Cmd+S`로 저장
4. `Cmd+Enter`로 실행 → 콘솔에 `[claude-vimium] ready`

**그다음 앱 창을 클릭해 포커스를 옮긴다.** DevTools에 포커스가 있으면 키가 전부 DevTools로 간다.

## A. teardown 누수 (Important 3)

재실행할 때마다 오버레이 div가 쌓이던 문제. 콘솔 붙여넣기가 이 프로젝트의 유일한 실행 방식이라 매 세션 누적됐다.

1. Snippets에서 `Cmd+Enter`를 **한 번 더** 눌러 재실행한다 (총 2회 실행 상태)
2. 콘솔(Console 탭)에서:

```js
document.querySelectorAll('#claude-vimium-overlay').length
```

**기대: `1`**

`2` 이상이면 teardown이 오버레이를 정리하지 못한 것이다. 세 번, 네 번 실행하면서 숫자가 늘어나는지도 보면 확실하다 — 계속 `1`이어야 한다.

## B. 모디파이어 조합 (Important 1) — 이번에 뒤집은 결정

이전에는 힌트 모드에서 `Cmd+C`를 누르면 라벨 `c`가 입력되는 것으로 처리됐다. 그런데 그게 라벨을 **완성해서 그 요소를 클릭**까지 하는 동작이었다. 기본 문자셋 `asfgqwertzxcv`에 `a s c v r`이 모두 있어서 `Cmd+C`·`Cmd+V`·`Cmd+R`·`Ctrl+A`·`Ctrl+S`가 전부 걸렸다. 삭제 버튼에 `v` 라벨이 붙어 있으면 `Cmd+V` 한 번이 파괴적이다.

1. 대화 아무 곳의 텍스트를 드래그해 선택한다
2. `Ctrl+;`로 힌트를 띄운다
3. `Cmd+C`를 누른다

**기대:**
- 힌트가 그대로 있거나 사라지되, **어떤 버튼도 눌리지 않는다**
- 어딘가에 `Cmd+V`로 붙여넣어 보면 복사가 됐다

`Cmd+V`, `Ctrl+A`도 같은 방식으로 확인한다. **버튼이 눌리거나 화면이 바뀌면 실패다.**

한 가지 더 — `Shift`는 막지 않았다. 대문자 입력 수단이기 때문이다. 라벨 입력 중 `Shift`를 누른 채 글자를 쳐도 라벨이 정상 매칭돼야 한다.

## C. Ctrl + Home / End / 방향키 (Minor 6)

Ctrl 조합이 `d`/`u`가 아니면 그 아래 분기로 못 내려가서 죽어 있었다.

힌트를 띄운 상태에서:

| 키 | 기대 |
|---|---|
| `Ctrl+Home` | 대화 맨 위로 |
| `Ctrl+End` | 대화 맨 아래로 |
| `Ctrl+↓` / `Ctrl+↑` | 아래/위로 스크롤 |

**아무 반응이 없으면 실패다.** 참고로 `Home`/`End` 단독과 `Ctrl+d`/`Ctrl+u`는 원래 되던 것이니 함께 확인하면 좋다.

---

## D. 스트리밍 중 라벨 (Important 2)

응답이 스트리밍되며 리렌더될 때, DOM에서 떨어져 나간 요소의 라벨이 되살아나 화면 좌상단에 쌓이던 문제.

1. Claude에게 **긴 응답**을 요청한다 (예: "아무 주제나 열 문단으로 길게 설명해줘")
2. 응답이 **스트리밍되는 도중에** `Ctrl+;`로 힌트를 띄운다
3. 라벨 문자를 **한 글자** 입력한다
4. 화면 좌상단(0,0 근처)을 본다

**기대:**
- 좌상단에 라벨이 무더기로 겹쳐 쌓이지 않는다
- 남아 있는 라벨을 완성하면 실제로 그 요소가 눌린다 (아무 일도 안 일어나고 모드만 꺼지면 실패)

스트리밍이 끝난 뒤에도 몇 번 반복해보면 재현 확률이 올라간다.
